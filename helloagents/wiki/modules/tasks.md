# tasks

## 目的
定义并承载 Nitro `task`，用于在定时触发（或手动触发）时执行签到/领奖逻辑。

## 模块概述
- **职责:** 多账号循环、调用签到接口、汇总结果、触发通知推送
- **状态:** ✅稳定（用于本地/服务侧调试）
- **最后更新:** 2026-02-13

## 规范

### 需求: 多账号每日签到
**模块:** tasks
对多个 Cookie 执行每日签到，并输出可读的摘要结果。

#### 场景: 定时执行
在 Nitro `scheduledTasks`（服务常驻场景）触发时运行。
- 预期结果1: 每个账号返回成功/已签/未登录/失败等状态
- 预期结果2: 汇总统计并推送通知（如配置）

#### 场景: 手动执行
在本地启动 Nitro dev 后，通过 tasks endpoint 手动触发一次执行。
- 预期结果: 与定时执行一致
